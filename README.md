## Featured Projects

### MergeMind — AI-Powered GitHub PR Code Review System
**Python • FastAPI • Celery • Redis • PostgreSQL • SQLAlchemy • OpenAI GPT-4o-mini • GitHub Webhooks • Next.js • TypeScript**

Built an AI-powered GitHub PR code-review pipeline that processes PR webhooks, analyzes changed files, generates structured AI review findings, stores results in PostgreSQL, and posts review summaries to GitHub.

Implemented language-specific review prompts for Python, JavaScript, TypeScript, and Java, covering logic, security, performance, and maintainability issues with structured JSON responses and confidence scores.

Added SHA-256-based review caching and idempotency to reuse completed file reviews and avoid duplicate GitHub review comments; built a Next.js dashboard for review history, findings, repository statistics, and cache metrics.

[Repository](https://github.com/Vanishagupta18/mergemind) · [Live Demo](https://mergemind-sigma.vercel.app/)

Developed RESTful APIs using Node.js, Express.js, and MongoDB/Mongoose for authentication, product, cart, and order functionality, integrating the React frontend with backend services.

Added an AI-assisted product discovery workflow using OpenAI for natural-language intent extraction, with validation, rule-based fallback, and matching against the product catalog.

Deployed with frontend on Vercel and backend on Render.

[Repository](https://github.com/Vanishagupta18/INDIANIME-3D-MERCH-CUSTOMIZER) · [Live Demo](https://indianime-3-d-merch-customizer-zck9.vercel.app/)
